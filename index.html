Una página web se construye en tres capas

HTML le da estructura, CSS le da estilo y JavaScript le da comportamiento. Activa cada capa y observa cómo la misma tarjeta pasa de texto plano a una pieza interactiva.

Solo HTML: el navegador muestra el contenido con su estilo por defecto. Ya es una página, pero sin diseño ni interacción.

¿Por qué aprender desarrollo web hoy?

+5.500 Mpersonas usan internet en el mundo (UIT, 2024)
+1.000 Msitios web registrados en la red (Netcraft)
≈ 98 %de los sitios web usan JavaScript en el navegador (W3Techs)

Dónde está la web, aunque no se note

  • Banca en línea, pagos y comercio electrónico.
  • Plataformas educativas y LMS como Moodle, donde viven los cursos virtuales.
  • Apps de escritorio construidas con tecnologías web (VS Code, Teams, Slack).
  • Trámites de gobierno digital, citas médicas y portales de servicios.
  • Interfaces de herramientas de inteligencia artificial, que se usan desde el navegador.

Lo que abre a quien lo domina

  • Frontend: diseña y programa lo que el usuario ve y toca.
  • Backend y full stack: conecta la interfaz con datos y servidores.
  • Diseño UX/UI y accesibilidad: productos que cualquier persona puede usar.
  • Emprendimiento: publicar una idea en internet cuesta muy poco con estas tres tecnologías.
  • Trabajo remoto: es una de las áreas con más ofertas para equipos distribuidos.

HTML · HyperText Markup Language

HTML: la estructura del contenido

HTML no es un lenguaje de programación: es un lenguaje de marcado. Usa etiquetas para decirle al navegador qué es cada cosa: un título, un párrafo, una imagen, un enlace.

Estructura base de todo documento

      
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
    <link rel="stylesheet" href="estilos.css">
  </head>
  <body>
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
    <script src="app.js"></script>
  </body>
</html>

      
    
        
  • <head>: información para el navegador (título, codificación, estilos). No se ve en pantalla.
    • 
        
  • <body>: todo lo que el usuario ve.
    • 
        
  • header, main, footer: etiquetas semánticas que dan significado y mejoran la accesibilidad y el posicionamiento en buscadores.

  CSS · Cascading Style Sheets
  
CSS: el estilo y la disposición

  
CSS selecciona elementos del HTML y les aplica reglas visuales: colores, tamaños, tipografía, espacios y la forma en que se ordenan en la pantalla.


  

    
Sintaxis de una regla

JavaScript sí es un lenguaje de programación. Guarda datos, toma decisiones, repite tareas y, sobre todo, modifica la página cuando el usuario hace algo.

El DOM: cómo JavaScript habla con HTML

    
El navegador convierte el HTML en un árbol de objetos llamado DOM (Document Object Model). JavaScript puede buscar un elemento, escuchar un evento y cambiar su contenido o estilo.

    
const boton = document.querySelector("#miBoton");   // 1. Buscar el elemento
boton.addEventListener("click", () => {              // 2. Escuchar el evento
  document.querySelector("#saludo").textContent = "¡Hola!"; // 3. Modificar la página
});
